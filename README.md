# 🚀 DigiTools – Premium Digital Tools Platform

DigiTools is a modern web application that provides a collection of premium digital tools to boost productivity and creativity. Users can browse products, add them to cart, and manage purchases with a smooth and responsive UI.

---

## 🌐 Live Features

✨ Beautiful UI based  
🛒 Add to cart & remove functionality  
📊 Static stats & pricing sections  
🔄 Toggle between Products & Cart  
📱 Fully responsive design  
🔔 Toast notifications for actions  

---

## ⚙️ Technologies Used

- ⚛️ React.js
- 🎨 Tailwind CSS & DaisyUI
- 📦 JavaScript (ES6+)
- 🔔 React-Toastify
- 📁 JSON (for product data)

---

## 🧩 Core Features

### 🧭 Navbar
- Dynamic cart count
- Sticky navbar on scroll

### 🎯 Banner
- Heading, description, buttons
- Image section

### 📊 Stats Section
- Clean UI with key statistics

### 🔄 Product & Cart Toggle
- Default: Products section
- Toggle to Cart view
- Empty cart message shown initially

---

## 🃏 Product Section

- 3-column responsive layout
- Each card includes:
  - Name
  - Description
  - Price & period
  - Tag (Popular / New / Best Seller)
  - Features list
  - Icon
  - Buy Now button

---

## 🛒 Cart Functionality

- Add product to cart
- Remove individual product
- Show total price
- Navbar updates cart count dynamically

### 🧾 Cart Features
- Product name, icon, price
- Remove button
- Total calculation

### ✅ Checkout
- “Proceed to Checkout” button:
  - Clears cart
  - Shows toast notification

---

## 🔔 Toast Notifications

Using **React-Toastify**:
- ✅ Added to cart
- ❌ Duplicate item select not allow
- ❌ Removed from cart
- 🛒 Checkout successful
